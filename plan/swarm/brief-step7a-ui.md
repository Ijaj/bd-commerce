3. `/suppliers/$id`: header with name + status badge + actions (Pause/Reactivate, "New purchase order" → `/purchase-orders/new?supplierId=`). StatTiles: Balance owed, Open POs, Linked products. Tabs:
   - **Details**: mockup drawer fields as an editable form (contact, ship mode radios with the mockup's helper texts, pickup address, payment terms, notes), Save.
   - **Products**: links table (product + options, SKU, supplier SKU, cost, our current cost, lead time days, default badge), inline edit modal (PUT), remove (DELETE, confirm via Mantine modal, not `window.confirm`). 4. Tests: list renders + filter, add supplier validation, ledger payment form converts ৳→paisa and requires reference for bKash, reverse only on eligible rows.
